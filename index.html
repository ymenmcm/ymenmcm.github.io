HOW TO SHARE

如何把文件变成可访问链接

文件不需要上传到本站，只要放在一个公开网页里。

提示

URL 不是一种新的文件格式，而是文件在网络上的访问地址。 先把文件上传到公开网盘、GitHub 或其他网页平台，再把获取到的地址提交到上方表单。

01 最推荐

网盘公开分享

适合 PDF、DOCX、ZIP、数据包和图片，操作最简单。

  1. 把文件上传到 Google Drive、OneDrive、百度网盘等。
  2. 点击“分享”，将权限改为“知道链接的人可查看”。
  3. 复制分享地址，提交到“题目 / 文章 / 代码”对应分区。
https://你的网盘域名/分享地址 去发布网盘链接 ↗
02 适合整套资料

GitHub Pages

适合论文 PDF、代码项目或需要长期展示的静态网站。

  1. 创建一个公开 GitHub 仓库并上传文件。
  2. 进入 Settings → Pages，选择 main 分支根目录。
  3. 复制生成的 Pages 地址，提交到本站。
https://用户名.github.io/仓库名/论文.pdf 查看 GitHub Pages ↗
03 适合代码

代码仓库

源码、Notebook 和运行说明可以直接使用仓库地址。

  1. 把项目上传到 GitHub 或 Gitee 公开仓库。
  2. 确认仓库无需登录即可访问。
  3. 复制仓库主页地址，提交到“代码”分区。
https://github.com/用户名/项目名 创建代码仓库 ↗
✓ 发布前检查
  • 用无痕窗口打开链接，确认不用登录也能访问
  • 不要提交会过期、只能本人打开或需要提取密码的链接
  • 文件名和说明写清楚，方便其他同学辨认版本
使用方式

三步分享资源

文件保存在你自己的平台，网站只整理入口。

01

准备公开链接

可使用网盘公开分享页、GitHub 仓库、Pages 网站、Notion 页面等。

02

选择分区

把链接放入题目、文章或代码分区，并填写标题和简要说明。

03

自由访问

所有访客都能查看和打开链接，原始文件的权限由发布者控制。
